# Crypto radar

监控 BTC、ETH、SOL 的 OKX USDT 永续顺势回踩机会。只生成提醒，不连接账户或下单。2026-10-21 起新策略与追踪层同源，均使用 OKX v5 公开接口，单一数据源不做跨市场回退。

## 策略数据

4H/1H 指标仅使用已收盘、连续完整的 K 线（OKX confirm 字段过滤，未收盘 bar 永不进指标）；4H 至少 750 根用于 EMA200 预热。永续最新价、买卖报价、标记价、资金费率独立获取。结算周期按接口时间戳推导并以 8 小时为预算上限——OKX 费率极低时会跳过某次结算，观测间隔可达 16 小时，此时按 8 小时保守预算成本。数据缺失、过期或接口异常时拒绝新策略，不降级到现货行情或其他交易所数据。

OKX 公开接口本机直连可用；本地模拟测试不代表真实信号或盈利表现。追踪层指标同样只取已收盘 K 线，实时价取自 ticker。

## 入场筛选

4H EMA20/50/200 排列、EMA20 最近三个收盘间隔斜率、ADX≥22、DI 方向及收盘价需一致。1H 最近四根 K 线要有均线回踩/反弹证据，最新收盘需重新站回均线、突破上一根高/低点并有同向 RSI 改善。多头 RSI 40–65，空头 35–60。

只接受最新 1H 收盘后 45 分钟内的确认。现价距离 1H EMA20 最多 1.5 ATR、4H EMA20 最多 2 ATR、确认收盘最多 0.5 ATR；重新失守或价格跑远即放弃。阈值是待验证的明确筛选口径，不代表胜率；更严格筛选可能显著减少机会。

## 点位、成本与风险

入场区间为确认时刻买卖价 ±0.1 ATR（即时入场，超出不追）；价差或标记价偏离过大即放弃。止损取近端结构外沿（结构 ±0.25 ATR）与 1.5 ATR 的更远者，上限 3 ATR 且不超过价格的 3%；TP1/TP2 按最不利入场扣除双边 taker 费率、滑点与不利资金费后的净 2R/3R 求解，目标与已确认结构边界间须留 0.25 ATR 空间，未知空间不当作目标。仓位按单笔风险不超过账户权益 0.5%、名义价值不超过权益计算；OKX 合约为张数模式（1 张 = ctVal 个币），数量按整数张向下取整，凑不足最小张数即放弃，不加仓凑单。

推送前用新行情复核信号方向与入场区间，失效即放弃本轮推送，不改点位硬推。AI（Gemini）仅作消息面否决：只能以重大风险拦下推送，不能修改点位或解释策略成立；复核调用失败时放行，不依赖单一外部模型。

## 推送流程

全币种扫描确认机会后按可比指标择优（4H ADX 优先，并列时取按 1H ATR 归一的 4H EMA20 贴近度），一次只推一个策略；首选候选构建失败不阻断其余候选。有未结案信号在追踪时不推新策略。推送文案与存档点位由同一份规则计划生成，追踪档案只存点位、预案与文案。

阈值与盈亏比是待验证的筛选口径，不代表回测过的收益优势；本地模拟与公开行情检查不构成真实信号。
